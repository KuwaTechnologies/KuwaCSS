# KuwaCSS

A 150-word UI vocabulary that humans and AI both speak fluently. One file. No build. No JavaScript.

KuwaCSS styles plain semantic HTML so it looks finished, adds named layout primitives (`stack`, `row`, `grid`, `sidebar`, `cover`) that are responsive without breakpoints, and a small, hole-free utility grammar. It ships a context file for language models and a validator that checks their output.
